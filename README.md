## 👋 Sobre mim

Olá! Sou **José Eduardo de Souza**, criador da **Souzas Dev**, minha identidade pessoal na área de tecnologia.

Estou construindo minha trajetória em **Cloud Computing, Desenvolvimento de Software e Automação**. Atualmente, estudo **AWS na Escola da Nuvem** e aprofundo meus conhecimentos em **Linux, Bash, Python, PowerShell, Git/GitHub e desenvolvimento web**.

Gosto de entender como as tecnologias funcionam por dentro: infraestrutura, sistemas operacionais, lógica de programação, estrutura dos códigos e comportamento das aplicações. Uso este GitHub como **portfólio de aprendizagem prática**, com laboratórios, scripts, documentação, resultados e pontos que ainda preciso melhorar.

Minha experiência anterior em **vendas e atendimento ao cliente** complementa essa jornada com comunicação, organização e resolução de problemas.

> 🎯 **Objetivo de longo prazo:** evoluir para **Engenharia de Nuvem (Cloud Engineer)**, construindo uma base consistente em infraestrutura, programação, automação e serviços de nuvem.

## 🚀 Projetos em destaque

Os projetos abaixo representam atividades de estudo e experiências **documentadas**, não produtos comerciais ou comprovação de domínio avançado.

### ☁️ [AWS Lab — Laboratórios de Cloud](https://github.com/Souzas-Dev/AWS-Lab)

Prática com serviços AWS, documentação técnica, scripts e evidências de laboratório.

- **EC2:** provisionamento, instâncias Linux, armazenamento EBS, monitoramento e ciclo de vida.
- **VPC + servidor web:** sub-redes, tabelas de rotas, Security Groups, EC2 e Apache.
- **Abordagem:** organização de evidências, noções de segurança, monitoramento e controle de custos.
- **Status:** laboratório em evolução; a documentação também registra verificações e limitações pendentes.

**Stack:** AWS · Amazon EC2 · VPC · EBS · Amazon Linux · Bash

📁 [Explorar o repositório](https://github.com/Souzas-Dev/AWS-Lab) · [Laboratório EC2](https://github.com/Souzas-Dev/AWS-Lab/tree/main/EC2) · [Laboratório VPC](https://github.com/Souzas-Dev/AWS-Lab/tree/main/VPC)

### 🐧 [Ubuntu Workstation Setup — Linux & Automação](https://github.com/Souzas-Dev/ubuntu-workstation-setup)

Projeto de estudo para automatizar a preparação de um ambiente Ubuntu com ferramentas úteis para desenvolvimento e suporte.

- **Bash:** atualização de pacotes, verificações do sistema e instalação de utilitários.
- **Segurança e qualidade:** modo de simulação (`--dry-run`), registros de execução, tratamento básico de erros e testes Bash.
- **Python:** protótipo experimental de interface com PySide6 (Qt).
- **Status:** versão `v1.2.0` documentada; testes de integração em Ubuntu e validação da interface ainda são pontos de evolução.

**Stack:** Linux · Ubuntu · Bash · Git · Python · PySide6

📁 [Explorar o repositório](https://github.com/Souzas-Dev/ubuntu-workstation-setup) · [Código do script](https://github.com/Souzas-Dev/ubuntu-workstation-setup/blob/main/scripts/setup-ubuntu.sh)
